# 🏷 Currency Weather CLI

A bash program that enables freelancers who get paid in foreign currency to track the rate with respect to weather.

---

## 📌 Problem Statement

Freelancers in Cameroon get paid in dollars and euros, and plan their day around the rain. Build fx.sh, a currency converter that uses live exchange rates, and meteo.sh, a weather tool for any city. These are your first programs that talk to the internet.
